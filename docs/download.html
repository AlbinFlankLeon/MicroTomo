MicroTomo v0.1.0

60 GHz surface-contour simulator — edit scenes, place transceivers, run a DAS reconstruction, and rotate the 3D result.

Latest release — v0.1.0

Download microtomo-0.1.0.tar.gz   All releases

Linux · ~2–5 min install · requires Python 3.10+ and a 64-bit system with OpenGL.

Install

tar -xzf microtomo-0.1.0.tar.gz && cd microtomo-0.1.0
bash install.sh
./launch_gui.sh

Verify

Checksum: dist/SHA256SUMS in the tarball, or run sha256sum microtomo-0.1.0.tar.gz.
